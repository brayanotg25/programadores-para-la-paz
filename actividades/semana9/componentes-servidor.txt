Sistema operativo:
Es el software que administra el hardware y los recursos del computador.
Permite ejecutar programas y servicios necesarios para el servidor.

Node.js:
Es un entorno que permite ejecutar código JavaScript fuera del navegador.
Se utiliza para crear aplicaciones y servidores web.

Aplicación server.js:
Es el archivo donde se encuentra el código del servidor.
Define las rutas, funciones y respuestas de la aplicación.

Puerto:
Es un número que identifica un servicio o aplicación en el servidor.
Permite que el servidor reciba solicitudes de los usuarios.

Logs:
Son archivos que registran eventos, accesos y errores del sistema.
Ayudan a monitorear el funcionamiento y solucionar problemas
